Website settings

Paste the full URL you normally use for each service, including your company's internal Farzi address if applicable.

When enabled, the extension removes X-Frame-Options and Content-Security-Policy response headers only for the configured site hosts when they are loaded as frames. This weakens those sites' browser security protections in the embedded view. Enable only for sites you trust. It cannot bypass every restriction or guarantee login/cookies will work.

Still not loading?

Some sites detect embedding or rely on cookies and browser features that don't work in a side-panel frame. Use the ↗ button to open that site in a normal tab. The extension can't force every website to behave like a full browser tab.
